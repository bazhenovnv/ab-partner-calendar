AB Partner Calendar — обновление по задаче

Выполненные доработки:
1. Витрина календаря
- Панель фильтров перенесена ниже блока важных событий и перед календарём.
- Нижний блок тем событий перенесён наверх страницы.
- Убрано лишнее вложенное оформление у фильтров/календаря, усилены тени карточек.
- Вкладки событий выбранного дня подняты выше заголовка события.
- Увеличены высота и межстрочный интервал вкладок событий, чтобы текст не обрезался.
- Добавлен подвал: «АБ Партнер 2022-<текущий год>» и «Краснодар <текущий год>».
- Нижняя панель подписана «Возможности платформы:».
- Обновлены подписи по синхронизации с источниками вместо Telegram там, где это относится к импорту.

2. Админка
- Раздел «Импорт из Telegram» переименован в «Импорт из источников».
- Добавлен клиентский guard: при отсутствии токена идёт редирект на /admin/login.
- Раздел «Кабинет организатора» расширен: вывод подключённых источников и кнопка ручной синхронизации.
- Раздел «Рассылка» расширен: поиск подписчика и отправка персонального ответа.
- В форме создания/редактирования события добавлена загрузка изображения файлом с предпросмотром.
- В дашборде уточнены счётчики мероприятий и импортов.
- Обновлены тексты в настройках и диагностике.

3. Backend
- Обновлён SourceConnectorsService: поддержка разных источников, MAX, автосинхронизация по интервалу.
- Добавлен backend endpoint для ответа конкретному подписчику.
- Счётчики дашборда переведены на активные/опубликованные записи.
- Аналитика берёт только активные опубликованные события.

Важно:
- Для персональных ответов и рассылок Telegram-бот должен быть корректно запущен на сервере.
- Для автосинхронизации должны быть заданы переменные окружения источников.
